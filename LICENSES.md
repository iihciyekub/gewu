# GEWU - Licenses and Credits

## About GEWU

**GEWU** — A workspace for dissecting texts and composing knowledge.

GEWU is a powerful research workspace supporting JSON structured data, Markdown note editing, PDF document viewing, and network visualization.

**Version**: 0.0.1
**Author**: @iihciyekub
**Repository**: Docker Hub: [iihciyekub/gewu](https://hub.docker.com/repository/docker/iihciyekub/gewu)

---

## Core Features

- **Project Management**: Create and manage multiple research projects
- **File Organization**: Automatic management of JSON data, Markdown notes, and PDF files
- **Structured Editing**: Visual JSON editing and validation
- **Markdown Editor**: Built-in Markdown editor with live preview
- **PDF Viewer**: Integrated PDF viewing
- **Network Visualization**: vis-network based citation and relationship graphs
- **Bibliography Management**: Citation.js powered citation formatting and management
- **Auto Save**: Real-time saving without losing progress
