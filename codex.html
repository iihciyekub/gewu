一键打开 Termius 并连接（然后跑 Codex）

打开 Termius 连接主机
打开 Termius（端口 2222）

连接后自动进入 Codex（推荐做法）

浏览器/URL 通常不能可靠地把“要执行的命令”传给终端 App，所以建议你在远端做“登录后自动进入 codex 会话”。

在远端服务器上（或你的 Mac mini 上）把下面这一段加到 ~/.zshrc 或 ~/.bashrc：

# 仅在 SSH 登录时自动进入 codex（避免本地终端也被影响）
if [ -n "$SSH_CONNECTION" ]; then
  # 方式A：如果有 tmux，自动进入/创建一个叫 codex 的会话并运行 codex
  if command -v tmux >/dev/null 2>&1; then
    tmux new -A -s codex "codex"
  else
    # 方式B：没有 tmux 就直接启动 codex
    codex
  fi
fi

这样你点上面的链接 → Termius 连上去后，就会自动进入 codex。

提示：首次点击 ssh:// 链接，浏览器通常会弹窗问你是否允许打开 Termius（或其他 SSH 应用）。
